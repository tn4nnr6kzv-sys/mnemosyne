Multi-appareils

Synchronisation

Ta bibliothèque est enregistrée dans un fichier .json d'un dépôt GitHub privé à toi. Chaque appareil le lit et l'écrit avec un jeton d'accès. Le jeton reste uniquement sur cet appareil et n'est envoyé qu'à GitHub.

Non configuré.
Comment créer le dépôt et le jeton (une seule fois)
  1. Crée un dépôt privé sur GitHub, ex. mnemosyne-data (vide, sans README).
  2. github.com → photo de profil → Settings → tout en bas Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Repository access : Only select repositories → choisis mnemosyne-data.
  4. Permissions → Repository permissions → Contents : Read and write.
  5. Generate token, copie-le (il commence par github_pat_) et colle-le ci-dessus. Renseigne ton pseudo et le nom du dépôt, puis Enregistrer et Envoyer une première fois.
  6. Sur un autre appareil : mêmes réglages + même jeton (ou un second jeton), puis Récupérer.

Modèle « dernier qui écrit gagne » : si tu modifies sur deux appareils sans synchroniser entre-temps, la dernière écriture prime. Chaque envoi crée un commit daté (donc un historique de sauvegardes).
